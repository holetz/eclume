O app desktop grava reuniões e notas de voz no computador e envia tudo para este servidor.

## Baixe o instalador

Abra [App desktop](/app-desktop). O instalador do seu sistema aparece primeiro, com o botão
**Baixar**. Os outros formatos, como o MSI no Windows e o `.deb` no Linux, ficam logo abaixo.

O instalador baixado daqui já conhece este servidor. Na primeira execução, o app mostra o endereço
com a indicação "Veio com este instalador", e você só entra com o seu e-mail e a sua senha do
eclume.

## O aviso da primeira execução

Os instaladores do eclume não são assinados por uma loja de aplicativos, então o sistema avisa na
primeira vez:

- **Windows:** na tela do SmartScreen, use **Mais informações** e depois **Executar assim mesmo**.
- **Linux:** instale o `.deb` pelo gerenciador de pacotes, ou marque o AppImage como executável.

O aviso não volta nas próximas vezes.

## Instalou de outro lugar?

Um instalador que não veio deste servidor não sabe o endereço dele. No app, escolha
**Vincular com um código** e digite o código que a página [App desktop](/app-desktop) gera.
