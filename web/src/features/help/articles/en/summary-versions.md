Every change to the summary creates a new version. No change erases the previous one.

## The origins of a version

- **Generated:** the agent wrote it from the agenda type's instructions.
- **Manual:** you edited it by hand.
- **Chat:** the agent changed it at your request, through the adjustment chat.

The summary bar shows the origin and the number of the current version.

## Compare with the generated one

**Compare with the generated one** shows what changed between the current version and the last
version generated by the agent, passage by passage.

## Back to the generated one

**Back to the generated one** brings back the text of the last generated version. Going back also
creates a version, so your edits stay in the history and nothing is lost.

## The earlier-version summary warning

Each version remembers which transcript it came from. When the transcript changes afterwards (a
corrected utterance, a speaker renamed, linked to a person or joined to another), the summary bar
shows **Summary of an earlier version of the transcript**. **Regenerate** creates a generated version
on the transcript as it is now. While the agent writes the new version, the warning does not show.

## When a new generated version appears

A new generated version appears when you change the agenda type, ask for a new summary or
transcribe the recording again. While the agent writes, the current version stays on screen.
