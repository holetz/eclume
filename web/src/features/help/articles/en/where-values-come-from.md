In the recording's fields panel, each value has a badge that says where it came from.

## The badges

- **Automatic** (dashed outline): the agent filled it in by the field's rule and nobody checked it.
- **Accepted:** you checked the automatic value and accepted it as it is.
- **Edited** (solid outline): you wrote or changed the value.

## Accept

- **Accept**, beside an automatic value, confirms that value.
- **Accept all** confirms at once all of the recording's automatic values.

Accepting does not change the value's text: it only says it was checked.

## The golden rule

Automatic filling never overwrites an **edited** or **accepted** value. Transcribing the recording
again or changing the field's rule recalculates only the automatic values. What you checked stays.

To change what the agent fills in, adjust the field's rule in
[Custom fields](/config/campos): see [Write a rule that fills in a field](/ajuda/write-a-rule).
