The desktop app records meetings and voice notes on the computer and sends everything to this server.

## Download the installer

Open [Desktop app](/app-desktop). The installer for your system shows first, with the **Download**
button. The other formats, such as the MSI on Windows and the `.deb` on Linux, are right below.

The installer downloaded from here already knows this server. On the first run, the app shows the
address marked "Came with this installer", and you just sign in with your eclume email and password.

## The first-run warning

eclume's installers are not signed by an app store, so the system warns you the first time:

- **Windows:** on the SmartScreen screen, use **More info** and then **Run anyway**.
- **Linux:** install the `.deb` with the package manager, or mark the AppImage as executable.

The warning does not come back the next times.

## Installed from somewhere else?

An installer that did not come from this server does not know its address. In the app, choose
**Link with a code** and type the code the [Desktop app](/app-desktop) page generates.
