A recording made elsewhere (a recorder, a phone, a meeting downloaded from the video platform) gets
into your library through import.

## How to import

1. In the [library](/), use **Import files**. A window opens over the library.
2. Drop the files in the marked area or pick them on the computer. You can send several at once.
3. Check each file's date and use **Send**.

You can close the window during the upload: the queue goes on, and each file shows in the library as
soon as it arrives.

## Which files work

Most audio and video files. The browser converts the file to audio before sending, so a large video
goes up as audio only, much smaller than the original. The file on your computer does not change.

## The recording date

The date that counts in the library is when the recording started, not when it was uploaded. eclume
reads this date from the file's metadata before converting and shows where it came from:

- **From the file metadata**: the date the device wrote into the file itself.
- **No date in the file**: the file's modified date applies. Check it, because it may be the date of
  a copy.
- **Edited by you**: the date you fixed in the window.

Fix the date before sending whenever it does not match the day of the meeting.
