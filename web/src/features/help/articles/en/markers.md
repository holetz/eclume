A marker keeps an instant of the recording so you can find it later: a decision, a question, a
number to double-check.

## How to mark

- **In the desktop app:** use the **Marker** button in the window, the tray item or the shortcut
  (`Ctrl+Alt+M` on Windows and Linux, `⌘⇧K` on macOS). The window takes a short note.
- **On the phone:** tap **Marker** on the recording screen or in the notification, with the screen locked.

## What the marker keeps

- the instant in the audio;
- the note, if you wrote one;
- the device that marked, like "Phone · Ana" or the computer's name.

Markers go up together with the recording.

## On the recording page

Markers show as ticks on the player and in a list right below. Click a marker to hear that passage
and see the utterance in the transcript. You can edit the note and delete the marker.

## Where the note goes

The note does not stay only in the marker:

- **In the summary:** when the agent writes the summary, it receives your notes along with the
  transcript, each at the instant you marked. They guide what it highlights, but the summary text is
  the agent's: the note is not copied word for word. If you change a note later, ask for a new summary.
- **In the synced folder:** each recording's `.md` gets the **Marker notes** section, with one line
  per note and its time. A marker without a note does not go in. Since the file goes to your
  computer, the notes leave the server; see [Sync your summaries to a folder](/ajuda/synced-folder).
