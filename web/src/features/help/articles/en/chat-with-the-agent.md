The **Agent**, the first item in the menu, opens the [Agent](/agente) screen: there you talk in plain
language about your set of recordings and about the files you attach. This screen used to be called
Questions.

## How to ask

Write the question and click **Send** (or Ctrl+Enter). The Agent starts from the summaries and only
reads the transcripts when the summary is not enough. Each answer shows the recordings it relies on,
with the link to open them, and how many lookups the Agent made.

## Attach a file

Click **Attach** and choose up to five files per question: text (.txt), Markdown (.md), spreadsheet
as text (.csv), PDF or Word document (.docx), up to 10 MB each. The attachments show above the button
before you send; the **×** removes one. The Agent reads the file's text, so a scanned PDF, with no
text, shows as **no readable text**.

## Receive a file

Ask for the result as a file, such as "build a table with the deadlines" or "write the minutes in
Word". The Agent can return Markdown (.md), text (.txt), a table (.csv) or a Word document (.docx).
The file shows in the answer: click the name to download.

## Saved conversations

Each conversation is saved in your account, with the questions, the answers and the files. The recent
ones show beside the conversation; **New conversation** starts another. In
[Conversations](/agente/conversas), in the Agent group of the menu, all of them are kept: open one to
continue where you left off, rename or delete it. Deleting takes the messages, the attachments and
the generated files, and cannot be undone.

## Limits

Each conversation answers one question at a time, and the account has up to two answers in progress.
Questions count against your account's quota of agent requests, like the summaries and the
adjustments.
