A step that failed can almost always run again from the recording page itself.

## Try the transcription again

**Try again** on the transcription redoes the whole chain from it: transcription, field filling,
agenda type and summary. What you did by hand stays:

- field values you **edited** or **accepted** are not recalculated;
- the agenda type you **chose** stays the same;
- the speaker-to-person links you confirmed still hold.

Automatic values and the type picked by the agent are recalculated on the new transcript.

## Too many or too few speakers

**Try again** uses the platform's speaker limits. If the transcript split too many voices or too few,
use **Transcribe again in…** (available with the recording transcribed or failed) and fill in the
**Minimum speakers** and **Maximum speakers**. It is the same chain: text corrections are lost and the
fields, agenda type and summary are redone. A voice note already uses a single speaker.

## Other steps

- **Summary:** ask for a new summary on the recording. It uses the current agenda type's instructions.
- **Agenda type:** choose the type by hand with **Change**. The title, tags and summary are redone
  from the new type.
- **Fields:** fill in or fix the value by hand. An edited value is never overwritten afterwards.

If the same step fails again, tell whoever administers the server: the reason shows as text below
the step bar.
