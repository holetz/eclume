The agent picks each recording's agenda type, and sometimes gets it wrong: a customer conversation
becomes a team meeting, for example.

## How to change it

In the recording's fields panel, use **Change** beside the type and choose the right one.

## What the change redoes

- **Title:** built from the new type's pattern, if you did not edit or accept the title.
- **Tags:** the new type's default tags are added to the automatic ones.
- **Summary:** a new summary comes out from the new type's instructions. The previous one stays in
  the versions: see [Summary versions and Back to the generated one](/ajuda/summary-versions).

## The change is yours

The type you chose is not undone by automatic detection, not even when the recording is
transcribed again.

If the agent always gets the same type wrong, improve the **How to identify** of the types in
[Agenda types](/config/agendas): say what tells one from the other.
