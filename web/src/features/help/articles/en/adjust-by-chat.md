The **Adjust the summary** chat, beside the summary on the recording page, asks the server's agent
for changes in plain language.

## How to ask

Write what you want to change, as you would to someone who was in the meeting:

- "Split the decisions by area."
- "Include the deadline Ana gave for the proposal."
- "Make the summary shorter, with five items at most."

The agent works on the current summary and answers in the chat. When the answer changes the summary,
it becomes a **new version**, marked as chat.

## From the summary to the rule

The chat changes this recording's summary. To make the next ones come out that way too, take the
adjustment to the rule:

- After an adjustment that changed the summary, the chat offers **Take this request to the type
  instructions**. It opens the recording's agenda type with your request at the end of the summary
  instructions. Nothing is saved on its own: review the text and save.
- The type badge, above the summary, leads to the type in [Agenda types](/config/agendas) to adjust
  the instructions.
- In the recording's fields, **Edit the rule** opens the field in
  [Custom fields](/config/campos); the title leads to the agenda type and the tags to Tags.

## When the agent reads the transcript

The agent reads the transcript only when the request needs it, such as to find a deadline that is
not in the summary. Each read shows in the message, with the passage read ("Read the transcript,
00:03:20–00:04:20"), so you can check where the information came from.

## If the summary changed in the meantime

If another version came in while the agent was working, it overwrites nothing: the answer shows in
the chat without becoming a version, and you can ask again on the current summary.
