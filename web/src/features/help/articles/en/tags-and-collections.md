Tags and collections organize recordings in different ways, and a recording can have several of each.

## Tags

A tag marks a **subject**: "budget", "hiring", "planning".

- Tags live in a registry of yours, in [Tags](/tags). By default, the agent only applies the
  registered tags; if you want, you can let it create new tags, with a limit.
- Agenda types add their default tags.
- You add and remove tags in the recording's fields panel, and the new tag enters the registry on its own.

See [Register the tags and let the agent use them](/ajuda/registered-tags).

## Collections

A collection **groups recordings you choose**, like a mentoring program or a project with several
meetings. It has a name and a description, and nothing enters it on its own.

- Create and rename in [Collections](/colecoes).
- Put a recording in a collection from the recording's fields panel.
- Deleting a collection does not delete the recordings: they just leave the collection.
- In the desktop app, collections also become **subfolders** of the synced folder. See
  [Sync your summaries to a folder](/ajuda/synced-folder).

## In the library and in search

Both become filters in the [library](/) and in [search](/busca).
