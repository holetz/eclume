The link code ties the desktop app or the phone to your account without typing the server address.

## The code

- It has 6 characters, like `K7Q-4MX`.
- It is valid for 10 minutes and once only.
- A new code cancels the previous one.

The page shows how much time is left. Expired? Use **Generate another**.

## In the desktop app

In [Desktop app](/app-desktop), use **Generate a link code**. In the app, choose
**Link with a code** and type the code. This is only needed when the installer did not come from
this server: the installer downloaded from here already knows the address.

## On the phone

Open [Mobile app](/app-movel): the QR and the code show right away. In the app, tap
**Read a code** and point the camera at the QR. Without a camera, type the text code shown beside it.

When the device uses the code, the page shows **Paired** with its name.

## Unlink

The device list, on each page, shows when each one was paired and the last sync.
**Unpair** disconnects the app on that device until it signs in again.
