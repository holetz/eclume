      How the folder is organized
      • Collections become subfolders, each divided by month. Example: Clients/2026-09/. A recording in several collections appears in each; those without a collection go in sem-colecao. Organize collections in eclume on the web.
      • Names that sort by date. 2026-09-18_1100_01928f3a.md: date, time and recording reference (the same "ref." as eclume on the web). The title goes inside the file, rather than in its name.
      • Summary and transcript side by side. The summary is a .md with properties at the top; the transcript is a .jsonl with the same name.
      • Obsidian vault. Open the folder as a vault: Obsidian reads .md and ignores .jsonl, so transcripts do not clutter search or the graph.
      • Agent workspace folder. The app maintains an AGENTS.md at the root explaining to an agent (such as Claude Code) how to read and search the files.
      • It is a mirror. eclume overwrites the files it generated; edit a copy. Your own files in the folder are never touched.
