      Pasta local
      O resumo de cada gravação vira um arquivo Markdown e a transcrição, um arquivo JSONL, numa pasta deste computador. Vale para toda a sua biblioteca, não só para o que este computador gravou.

      Como a pasta é organizada
      • Coleções viram subpastas, e cada uma se divide por mês. Ex.: Clientes/2026-09/. Uma gravação em mais de uma coleção aparece em cada uma; as sem coleção ficam em sem-colecao. Organize as coleções no eclume web.
      • Nome que ordena por data. 2026-09-18_1100_01928f3a.md: data, hora e a referência da gravação (a mesma "ref." do eclume web). O título fica dentro do arquivo, não no nome.
      • Resumo e transcrição lado a lado. O resumo é um .md com propriedades no topo; a transcrição é um .jsonl com o mesmo nome.
      • Vault do Obsidian. Abra a pasta como vault: o Obsidian lê os .md e ignora os .jsonl, então as transcrições não poluem a busca nem o grafo.
      • Pasta de trabalho de agente. O app mantém um AGENTS.md na raiz que explica a um agente (como o Claude Code) como ler e pesquisar os arquivos.
      • É um espelho. O eclume sobrescreve os arquivos que gerou; edite uma cópia. Arquivos seus na pasta nunca são tocados.
