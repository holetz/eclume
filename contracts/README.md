# contracts

Fonte da verdade do contrato entre o eclume e as integrações (o lumea, primeiro): OpenAPI v1 da
API e JSON Schema da transcrição, com o mock server que deixa o importador do lumea evoluir sem o
backend real.

O conteúdo entra com a spec `contrato-api-v1` (holetz/eclume#3). Mudança incompatível aqui exige
nova versão do contrato (`v2`), nunca edição silenciosa da `v1`.
