# `vision/` — direction, by area

Where eclume is going (target state, "what and why"), **with no schedule**: one file per area
(`<area>.md`, `type: vision`).

**Boundary:** direction **carries no deadline, milestone or order**. A concrete task towards it is
a spec in the Quenching workspace (`cq specs list`); what **has already become reality** is
distilled into [standards/](../standards/index.md).

- [product.md](product.md) — the product vision: the confirmed record (users, purpose,
  positioning, brand commitments and principles), projected into the root `PRODUCT.md`, and the
  direction (target state, pillars that are already reality or still direction, and non-goals).
