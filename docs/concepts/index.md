# `concepts/` — conhecimento genérico que sustentamos

**Entendimento transversal** do time — conceitos de domínio (transcrição, diarização, impressão
de voz), modelos mentais e aprendizados que informam o trabalho sem serem contrato. Cada doc tem
`type: concept`.

**Fronteira:**

- vs. [standards/](../standards/index.md) — se vincula como o código é escrito, é padrão; aqui é
  o que **entendemos** (explicativo, não vinculante).
- vs. **external/** — fatos sobre um ativo **que consumimos** (WhisperX, pyannote, Tauri) vão para
  `external/` quando a home for instalada; aqui fica o entendimento genérico.
- vs. [vision/](../vision/index.md) — visão é **direção** futura; aqui é entendimento presente.
